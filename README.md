# Godot Tactical Study

使用 Godot 4 与 GDScript 制作的回合制战术学习原型。可试玩「义军呐喊」与「中学解救人质行动」，新增装备入包、换装 / 卸弹 / 只取弹药，以及原创几何校园潜入任务。

**评审入口：[三分钟作品介绍与贡献边界](PORTFOLIO.md)。** 代码由 AI 辅助实现，项目发起者主要负责需求设计、录像对照、手动试玩与验收；不宣称独立编写全部系统或完整移植原作。

## 打开与操作

银行教学关目前不在主菜单展示；仅调试时打开 `scenes/bank_tutorial.tscn` 用 F6 运行，再点击“进入银行”。银行是**自由操作学习版**，不再锁定 49 个目标格，也不以读完 49 条记录作为胜利条件。

- 点击头像或按 1–3 选择三名警员；什韦茨头像进入侦察，再点有外窗的房间并确认。侦察冷却三回合，不消耗警员 AP。
- 默认开启非强制方向指引：目标旁的黄色提示解释当前操作，蓝色人物虚影标出本回合落点，白线区分行动点范围。动作完成后自动选中下一条建议的警员并定位；期间仍可自由选人和移动，不会自动替玩家执行动作。空格或底部“定位并选人”可找回目标；交互仍须手动确认。建议可跳过、隐藏，未实现的系统会明确提示。
- 单击白色可达范围内的地面或蓝色虚影脚下，直接移动，不必再确认菜单。点不可达格会显示原因，不扣行动力。点击敌人身体显示喝止、警棍、泰瑟枪、射击或逮捕轮盘，悬停图标在底部显示说明与不可用原因。动作按钮在按下时触发；轮盘置于 GUI 输入最前层。若显示移动确认菜单，Enter、底部确认按钮或再点同一格也可确认；菜单打开时 Enter 不会误触换回合。
- 点击门窗，或点击其两侧格子，显示开门/开窗；须走到相邻格。读取原始纸条获得撬锁工具后，由持有工具的警员打开上锁木门；密码门弹出四位密码输入，取消或输错不扣 AP。已收集纸条可在齿轮菜单重读，不重复发放物品。点击人质可近距离解救。
- 点击选中警员可急救或装填；点击相邻受伤警员可为其包扎。每人起始一个急救包，包扎消耗一个包和 1 AP；R 装填手枪为 0 AP，银行暂沿用练习用的补弹，不含备用弹药守恒。
- 右键 / Esc 关闭动作菜单；Enter 换回合恢复 AP，移动/动作过程中不能重复下达动作或换回合。执行反馈短暂显示，原版说明放在场景目标旁，F1 可查看完整说明。
- WASD/方向键或滚轮平移镜头，中键切换总览。齿轮打开菜单，重开关卡和返回模式选择需确认；F1 查看帮助并手动翻阅原版说明。翻页不改变选人、镜头或世界状态。

人物交互已改为原版图标的动作轮盘，门窗保留小菜单，但还不是原版菜单的精确复刻。可完成本学习版的制服、解救及结算；当前战斗仍采用简化练习判定，射击/喝止结果不等于原版规则，敌人还没有完整回合 AI，不称为原版完整移植。

## 仍未达到 1:1 的部分

“49 步可走完”**不代表** 49 种动作和演出已还原。当前动作执行多为简化状态变化；虽然移动已使用原版邻接和距离规则，人员阻挡、停留限制及非移动动作的行动点规则尚不完整。原版的射击命中、换弹、敌人 AI/巡逻/警戒、视野与掩体、伤害、狙击侦察、撬锁/门窗动画、笔记内容、人质逃离、任务胜负条件等也尚未逐项实现。除警员行走与上述敌人状态的部分曲线外，其余原版动画、角色外观随机组合、定制卡通着色器、动态屋顶与完整 UI/音效未复刻；门窗目前只是原版网格的可见/隐藏，不是原版开启动画，部分玻璃也未转换。角色姿态仍缺 Unity Avatar 的精确肌肉求解，倒地过渡与受缚展示时间也为近似实现，不能称为 1:1。

要称为教学关 1:1，需将上述系统与原作实机的每一步画面、输入、行动力、镜头、动画、音效和结果逐项对照验收。现阶段不应把本项目当作成品。

## 主要文件

- `scenes/bank_tutorial.tscn`：启动场景。
- `scripts/bank_tactical.gd`：当前默认控制器，负责自由选人、屏幕角色/门窗拾取、动作菜单、条件验证与独立执行。
- `scripts/bank_guidance.gd`：非强制建议与本回合落点规划；按实际移动/互动状态推进，遇队友挡路时建议先让路，不自动移动任何人。
- `scripts/bank_tutorial_guided.gd`：共用数据加载、基础 HUD 和旧顺序流程；`scenes/bank_reference_sequence.tscn` 仅供旧序列回归测试，不是主场景。更早的 `scripts/bank_tutorial.gd` 也仅作参考。
- `scripts/bank_navigation.gd`：根据原版 `BattleGrid`/`NeighborsCellsMask`/`PathFinder` 规则执行八方向寻路、边界检查与距离计费。
- `scripts/bank_world.gd`：银行 3D 场景、角色与镜头。
- `scripts/bank_cop_source_pose.gd`：源互动曲线、身体旋转及手脚目标的近似重定向。
- `assets/characters/original_cop/interaction_source_curves.json`：源警员空闲、掩体、越窗、开窗、警棍、逮捕片段；由项目外 `work/convert_cop_interactions.py` 生成。
- `scripts/bank_enemy_animator.gd`：敌人状态到源片段的选择及近似骨骼表现，不包含 AI。
- `assets/bank/tutorial_data.json`：原始格子与边界、教学动作、中文文本和起始角色/门窗数据。
- `assets/characters/original_cop/walk_source_curves.json`：从原版 `walk.anim` 采样的 17 条 Humanoid 曲线和两个脚步事件；项目外 `work/convert_cop_walk.py` 可从源 `.anim` 重新生成。
- `assets/characters/original_cop/run_source_curves.json`：从控制器实际引用的 `run_0.anim` 采样的 21 条曲线与脚步事件；由项目外 `work/convert_cop_run.py` 生成，包含来源 GUID 与速度依据。
- `assets/characters/original_enemy_male/enemy_source_curves.json`：8 个敌人相关片段的采样数据，由项目外 `work/convert_enemy_animations.py` 生成。
- `assets/bank/original_scene`：银行静态场景 glTF 与源贴图。
- `assets/bank/openings`：按关卡源数据使用的原版门窗预制体网格。
- `assets/characters/original_cop`、`original_enemy_male`、`original_hostage_prostitute`：当前关卡实际使用的已转换角色资源。
- `assets/bank/ui/police_portraits_custom_10.png`：用户提供的十人拼图原文件，教学关与义军模式共用；运行时按 5×2 格裁切。原版头像图集留作可回退资料，但游戏内警员头像不再引用。
- `../Rebel.Cops.GodotAssetLibrary`：Godot 项目外的素材分类库，避免一次导入全部资源。

Unity 的 `.asset`、`.anim`、`.controller` 和 `.prefab` 不是 Godot 原生格式；此处的 glTF 转换了所列网格、骨骼和基础材质，未包含可直接播放的原版动画。警员行走和敌人状态只提取部分肌肉曲线作近似重定向，原版 Animator Controller 状态机与 Avatar 求解未转换。
