# Godot Tactical Study

使用 Godot 4 与 GDScript 实现的回合制战术学习工程，参考《Rebel Cops》的银行教学关和义军呐喊模式。

**本公开仓库仅包含项目代码、场景与配置。原游戏的模型、贴图、动画、音频、提取数据及程序未上传。项目依赖本地 `assets/`，克隆后不能直接运行。**

目前实现：行动点寻路与移动预览、掩体侧身与射击判定、敌人视听和最后目击位置追踪、手动警戒/反击、物品实例背包与换装/卸弹/交换、回合存档、伤情与大小急救包区别，以及 UI 动效。代码入口为 `scripts/horde_mode.gd`，战局规则、导航、AI、背包、动作播放分别在对应的 `horde_*.gd` 模块中。

最新验证：状态测试121项、伤情专项18项通过。倒地点击检测的最后修改仍待复跑；手动反击测试的一条旧死亡断言需要更新；动画重定向精度和退出资源残留仍待改进。此仓库尚非已完成的原版移植或可发布游戏。

本工程的个人实现与原作资源分别归其作者；未附带原作资源的再分发许可。后续公开可运行版本需补齐可再分发的替代资源。

以下为开发历史记录，其中较早的功能状态以以上最新说明为准。

# Rebel Cops · Godot 学习项目（历史记录）

包含保留的银行教学关和新增的**义军呐喊生存模式初版**，不制作整部游戏的剧情流程。这是进行中的个人学习项目，尚未达到原作 1:1。角色动作还原按用户要求暂停。

## 义军呐喊（2026-09-26）

F5 运行后先进入模式选择，点击“义军呐喊 / REBEL YELL”。已经接通原始地图、随机四人持刀开局、补给、回合制敌人 AI、递增波次、战斗交互和失败结算。详细来源、玩法与未还原部分见 [HORDE_MODE.md](HORDE_MODE.md)。本模式不覆盖银行关；从菜单确认后可返回模式选择。

新录屏 UI 对照：人物卡选中放大、AP 圆点、悬停展开的六栏装备面板、本人 / 敌人的动作轮盘、灰度模糊暂停菜单和指挥中心界面。点击本人打开动作轮；I 展开装备，C 指挥中心，M 显示战况地图。交易、弹夹投递、指挥能力仍未实现，界面已明确标灰；本轮没有更改动作与战斗规则。

## 打开与操作

用 Godot 4.7.2 打开本目录的 `project.godot`，用 F5 运行项目，模式选择中点“银行教学关”，然后点击“进入银行”。银行是**自由操作学习版**，不再锁定 49 个目标格，也不以读完 49 条记录作为胜利条件。

- 点击头像或按 1–3 选择三名警员；狙击手头像暂只提示尚未实现。
- 默认开启非强制方向指引：目标旁的黄色提示解释当前操作，蓝色人物虚影标出本回合落点，白线区分行动点范围。动作完成后自动选中下一条建议的警员并定位；期间仍可自由选人和移动，不会自动替玩家执行动作。空格或底部“定位并选人”可找回目标；交互仍须手动确认。建议可跳过、隐藏，未实现的系统会明确提示。
- 单击白色可达范围内的地面或蓝色虚影脚下，直接移动，不必再确认菜单。点不可达格会显示原因，不扣行动力。点击敌人身体显示喝止、警棍、泰瑟枪、射击或逮捕轮盘，悬停图标在底部显示说明与不可用原因。动作按钮在按下时触发；轮盘置于 GUI 输入最前层。若显示移动确认菜单，Enter、底部确认按钮或再点同一格也可确认；菜单打开时 Enter 不会误触换回合。
- 点击门窗，或点击其两侧格子，显示开门/开窗；须走到相邻格。读取原始纸条获得撬锁工具后，由持有工具的警员打开上锁木门；密码门弹出四位密码输入，取消或输错不扣 AP。已收集纸条可在齿轮菜单重读，不重复发放物品。点击人质可近距离解救。
- 右键 / Esc 关闭动作菜单；Enter 换回合恢复 AP，移动/动作过程中不能重复下达动作或换回合。执行反馈短暂显示，原版说明放在场景目标旁，F1 可查看完整说明。
- WASD/方向键或滚轮平移镜头，中键切换总览。齿轮打开菜单，重开关卡和返回模式选择需确认；F1 查看帮助并手动翻阅原版说明。翻页不改变选人、镜头或世界状态。

人物交互已改为原版图标的动作轮盘，门窗保留小菜单，但还不是原版菜单的精确复刻。当前战斗采用简化练习判定：动作范围、装备配置、射击/喝止结果不等于原版规则，敌人也还没有完整回合 AI。不能据此称为可完整通关的原版教学关。

## 仍未达到 1:1 的部分

“49 步可走完”**不代表** 49 种动作和演出已还原。当前动作执行多为简化状态变化；虽然移动已使用原版邻接和距离规则，人员阻挡、停留限制及非移动动作的行动点规则尚不完整。原版的射击命中、换弹、敌人 AI/巡逻/警戒、视野与掩体、伤害、狙击侦察、撬锁/门窗动画、笔记内容、人质逃离、任务胜负条件等也尚未逐项实现。除警员行走与上述敌人状态的部分曲线外，其余原版动画、角色外观随机组合、定制卡通着色器、动态屋顶与完整 UI/音效未复刻；门窗目前只是原版网格的可见/隐藏，不是原版开启动画，部分玻璃也未转换。角色姿态仍缺 Unity Avatar 的精确肌肉求解，倒地过渡与受缚展示时间也为近似实现，不能称为 1:1。

要称为教学关 1:1，需将上述系统与原作实机的每一步画面、输入、行动力、镜头、动画、音效和结果逐项对照验收。现阶段不应把本项目当作成品。
